Non-parametric model

As the data is small in batch sample size, not really normally distributed, with outliers that can’t be removed (because they are sizable portions of the sample size in their batches) and the response variable is ordinal (a ‘liking’ score), a non-parametric test is worthwhile performing. A GAM model (general additive model which fits here because the batch variable is categorical) shows that batch is weakly significant. In this model the s(Batch, bs = “re’) term treats the batch as a random effect. It assumes batches were randomised. While method = ‘REML’ results in better model estimation of variance components.

coffee_gam <- gam(Score ~ s(Batch, bs = "re"), data = data, method = 'REML')

Checking this with a Kruskal-Wallis test shows no significant difference between groups. Chi-squared value of 6.98 and P-value of 0.07. Fail to reject the null hypothesis.

Residual Analysis

Linear residuals

There is clear uneven variance between the residuals and the batches. Some have much larger variance than other batches. Batch 3 for example has far less variance, while batches 1, 2 and 4 have wide, but not even variance between groups. Indicating perhaps a confounding variable(s) at play. The residuals and fitted plot indicate a non-linear trend as there is a clear patern within and between groups. The residuals are not normally distributed, as the Q-Q plot show clear deviation from normality.
The scale location plot confirms the lack of homoscedasticity with an uneven trend line. The constant leverage plot indicates that the residuals are not evenly distributed across factor levels, but lack a clear trend. It would appear that batches 1 and 2 are more similar to each other, as are batches 3 and 4. These two pairs are not similar to each other. An autocorrelation plot show only one spike beyond confidence bands, indicating no serious auto-correlation. Which is confirmed by a L Jung test with lag of 2 which fails to reject the null hypothesis of no auto-correcaltion (P-valu 0.32).

Residuals are not normal: Normality assumption failed. Residuals are independent: Independence assumption passed. Residuals are heteroskedastic: Homoscedasticity assumption failed. Residuals are not linear: Linearity assumption failed.

Therefore, the conclusions drawn from this model are misleading.

Visualising results of non-paramteric test

Because the linear model assumptions failed, and the results of the non-parametric test were not-significant, it is worthwhile to look at the ‘residuals’ in a non-parametric way. Below the residuals are approximated by ranking the data and subtracting the medians from observed ranks. These non-traditional residuals can be viewed to spot any patterns between groups. The resulting box plot is very similar to the initial box plot. It shows no patterns across all groups, but does confirm that batches 1 and 2 are more similar to each other than batches 3 and 4. And vice versa.

data$ranks <- rank(data$Score)

# Compute residuals (rank - group median rank)
group_medians <- tapply(data$ranks, data$Score, median)
data$residuals <- data$ranks - group_medians[data$Batch]

# Plot residuals
ggplot(data, aes(x = Batch, y = residuals)) +
  geom_boxplot() +
  labs(title = "Residuals (Ranks - Batch Median Ranks)", y = "Residuals")

Statistical conclusion

There is no difference between estimated liking and the batches used in the experiment. The null hypothesis has failed to be rejected. Any difference between batches observed is the result of random noise.

Real world advice

These data were too few to get a decent analysis. There is perhaps a confounding variable or perhaps not enough experimental units to observe any trends through the random noise. Re-run this experiment with more experimental units per batch. Keep the four batches and the randomisation in the experiment, but run the experiment longer. Aim for 20 experimental units per batch as a minimum. Additionally, capture more data about the person being measured. At least their age and sex. And keep data about the setting of the measurements taken. Such as time of day and internal and external temperatures for starters. Perhaps these can help guide the analysis and isolate/identify the unknown confounding variable.

However, if you are happy with these results, then you can take it on faith that there is no difference between the groups and can proceed with the process which creates the most coffee at the lowest cost to you.
