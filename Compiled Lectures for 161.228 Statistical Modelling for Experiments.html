Preface

These notes were first developed for lectures for the course 161.222 Design and Analysis of Experiments, taught at Massey University by Raj Govindaraju and Jonathan Godfrey.

They have been modified to align with the course now taught to Statistics majors, Food Technology students, and any other students interested in experimental science under the new course number 161.228 and name “Statistical Modelling for Experiments” first used in 2026. The course is new in name but was taught under two paper numbers up to 2025.

We use R in almost every lecture; you should be able to run the code on your own. You should follow the instructions on how to get your own installation of R and RStudio on the help using R and RStudio in 161.228 page.

The material that follows often makes use of tidyverse packages. Graphs are made using a mixture of base R graphics and ggplot functions, with the choice being made on the basis of convenience. There is no sense using a lot of effort if the graph is simple and will only be seen by the analyst. More effort is warranted if the graph is likely to be enriched or used for a presentation.

Please ask for help if you don’t understand the R code being demonstrated.

These notes were written using R markdown. To process the files used in lectures, you will need a copy of the bibliography file used in creating them. Download Overall.bib and put it alongside the Rmd files you intend to process. N.B. This does not include the references for R packages.
